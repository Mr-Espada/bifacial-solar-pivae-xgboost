# Historical notebook

`historical/data_mu_std.ipynb` is a source-only copy of the original 21-cell notebook. Code is retained; outputs and execution counters are stripped for the public candidate. The complete original with seven embedded figures remains in the private original ZIP and original project folder.

This is **historical analysis**, not the reconstruction pipeline. It combines train and test for normalization and depends on a missing `mcmc_1000.csv`. Do not execute it as a claimed reproduction of published results. The first nine cells can run against authorized data in an isolated historical layout; full execution cannot be completed from retained files. The cleaned pipeline uses `src/pivae_hybrid/` and training-only preprocessing instead.
